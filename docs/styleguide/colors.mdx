export const Swatch = ({ name, from }) => (
  <div style={{ display: "flex", alignItems: "center", gap: "0.75rem", padding: "0.3rem 0", minWidth: 0 }}>
    <span
      aria-hidden="true"
      style={{

        flexShrink: 0,
        borderRadius: "6px",
        background: `var(${name})`,
        border: "1px solid var(--ifm-color-emphasis-300)",
      }}
    />
    <div style={{ minWidth: 0 }}>
      <code style={{ fontSize: "0.75rem", wordBreak: "break-all" }}>{name}</code>
      {from && (
        <div style={{ fontSize: "0.7rem", opacity: 0.6, marginTop: "0.15rem", wordBreak: "break-all" }}>
          ↳ {from}
        </div>
      )}
    </div>
  </div>
);

export const Swatches = ({ names }) => (
  <div style={{ display: "grid", gridTemplateColumns: "repeat(auto-fill, minmax(240px, 1fr))", gap: "0.25rem 1.5rem", marginBottom: "1.5rem" }}>
    {names.map((n) => {
      const [name, from] = Array.isArray(n) ? n : [n, null];
      return <Swatch key={name} name={name} from={from} />;
    })}
  </div>
);

Every colour-valued custom property from `src/css/variables.scss`, resolved live — so toggling the theme switch shows both palettes. Spacing, type and sizing tokens are in the table at the end. Swatch styling is inline on purpose, to keep this page from adding anything to the production stylesheet.

Where a token is an alias onto a brand variable, the target is noted beneath it with a `↳`. Some resolve differently per theme, written as `light / dark`; a side written `—` isn't aliased there — it's either an Infima default we never touched, or a one-off literal with no brand variable behind it.

## Infima primary

`--ifm-color-primary` maps to `--src-green-500` in light and `--src-highlight` in dark — `--src-primary` (`--src-green-400`) only hits 2.8:1 on white, short of the 4.5:1 text needs, so light mode anchors one step darker on the brand's own green scale instead. The `-dark` through `-lightest` variants are also `--src-green-*` steps, not a generated ramp; Infima uses `-dark` and `-darker` for `.button--primary` hover and active.

## Emphasis scale

The borders-and-fills ramp, aliased onto the gray ramp above. It's **inverted** in dark mode — `emphasis-0` is `gray-0` in light and `gray-1000` in dark — so toggling the theme reverses this row. That inversion is why these carry no fixed `↳` target. `emphasis-200` is the one the partials lean on most.

## Alerts and admonitions

Infima maps `.alert--secondary` to `:::note`, `--success` to `:::tip`, `--info` to `:::info`, `--warning` to `:::warning` (and its `:::caution` alias) and `--danger` to `:::danger`, so the families below are what the admonition variants actually resolve through. Info shares tip's fill. Warning and danger alias their accent onto a brand colour but keep Infima's contrast pairs, which vary per theme.
